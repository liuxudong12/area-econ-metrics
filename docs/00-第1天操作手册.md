## 一、先搞懂两个词

### `/ping` 接口

一个用来确认"服务还活着"的最简接口。你在浏览器访问它，它回你一个字符串。
跑通它等于一次性验证了四件事：**代码编译过了、Spring Boot 起来了、8080 端口没被占用、HTTP 请求能被正确处理。**

四个里任何一个出错，你都访问不到。所以先跑通最简单的，后面出问题才有排查的基准线。

（上线后运维用的"健康检查"就是这个原理，只是换成 `/actuator/health`。）

### `commit`

给代码打一个存档点。git 是代码的存档系统，`commit` 就是按一次"保存"。

```bash
git init                          # 第一次：把文件夹变成 git 仓库
git add .                         # 把改动放进"待提交区"
git commit -m "一句话说明"         # 存档
```

**面试官会看 commit 记录。** 十四条清晰的 commit 就是"我真的天天在写"的铁证。

## 三、第二步：写三个文件

Initializr 会自动生成启动类。你需要自己加两个文件。

### 文件 1 · 启动类（Initializr 已自动生成，确认一下路径）

`src/main/java/com/liuxudong/areaecon/AreaEconMetricsApplication.java`

```java
package com.liuxudong.areaecon;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class AreaEconMetricsApplication {

    public static void main(String[] args) {
        SpringApplication.run(AreaEconMetricsApplication.class, args);
    }
}
```

**逐行解释：**

- `@SpringBootApplication` —— 这是启动开关。它实际是三个注解的合体：标记这是配置类、开启自动配置、扫描当前包及子包下的所有 Bean。
- `SpringApplication.run(...)` —— 启动 Spring 容器、内嵌的 Tomcat、以及所有自动配置。
- **注意包名**：`com.liuxudong.areaecon`。Spring 默认只扫描**这个包和它的子包**。
  所以你的 Controller 必须放在 `com.liuxudong.areaecon` 下面，否则不生效——这是新手最常踩的坑。

### 文件 2 · `PingController`（你要写的核心）

路径：`src/main/java/com/liuxudong/areaecon/controller/PingController.java`

```java
package com.liuxudong.areaecon.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

/**
 * 健康检查接口：用来确认服务是否正常启动。
 */
@RestController
public class PingController {

    @GetMapping("/ping")
    public String ping() {
        return "pong";
    }
}
```

**逐行解释：**

| 代码 | 作用 |
|---|---|
| `@RestController` | 告诉 Spring：这个类是处理 HTTP 请求的，而且方法返回值**直接作为响应内容**返回（不是页面名） |
| `@GetMapping("/ping")` | 把「用 GET 方式访问 `/ping`」这个请求，交给下面这个方法处理 |
| `public String ping()` | 方法名随便取，不影响访问路径。真正决定路径的是 `@GetMapping` 里的值 |
| `return "pong";` | 返回的字符串会原样写进 HTTP 响应体，浏览器上就显示 `pong` |

**你应该能回答的问题：**
- 为什么这个类要放在 `controller` 子包下？（提示：包扫描范围）
- 如果把 `@RestController` 换成 `@Controller`，访问 `/ping` 会怎样？（提示：会去找一个叫 `pong` 的页面模板，然后 404）

### 文件 3 · `application.yml`

路径：`src/main/resources/application.yml`（如果 Initializr 生成了 `.properties`，把它删掉，用 yml）

```yaml
server:
  port: 8080

spring:
  application:
    name: area-econ-metrics

  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/area_econ?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: Root@1234
```

**解释：**

- `server.port: 8080` —— 服务监听的端口。被占用了就改成 8081。
- `spring.application.name` —— 服务名，日志里会显示，以后接注册中心会用到。
- `datasource.url` 里的参数一个都不能少：
  - `useUnicode=true&characterEncoding=utf8` —— 中文不乱码
  - `serverTimezone=Asia/Shanghai` —— 否则时间差 8 小时（MySQL 8 的经典坑）
  - `useSSL=false` —— 本地不需要加密连接
  - `allowPublicKeyRetrieval=true` —— MySQL 8 默认用 `caching_sha2_password` 认证，不加这个会报 `Public Key Retrieval is not allowed`
- `username` / `password` —— 就是刚才重置的 `root` / `Root@1234`

> ⚠️ **今天是本地练习库，密码直接写没问题。**
> 但养成一个习惯：真项目里数据库密码不要提交到 Git。做法是把密码放到环境变量，
> 或者新建一个 `application-local.yml` 并加进 `.gitignore`。

## 四、第三步：启动并验证

1. 在 IDEA 里点 `AreaEconMetricsApplication` 左边的绿色三角运行
2. 看控制台，出现这一行就说明起来了：
   ```
   Tomcat started on port 8080 (http)
   Started AreaEconMetricsApplication in x.xxx seconds
   ```
3. 打开浏览器访问：**`http://localhost:8080/ping`**
4. 页面上出现 `pong` → **第 1 天任务完成**

### 如果启动失败，按这几条对号入座

| 控制台报错关键词 | 原因 | 怎么处理 |
|---|---|---|
| `Access denied for user 'root'` | 密码错 | 检查 `application.yml` 里的密码 |
| `Unknown database 'area_econ'` | 库名错 / 库没建 | 回到 mysql 里 `SHOW DATABASES;` 确认 |
| `Public Key Retrieval is not allowed` | 少了 URL 参数 | 检查 `allowPublicKeyRetrieval=true` |
| `Port 8080 was already in use` | 端口被占 | 改成 `8081` |
| 访问 `/ping` 返回 404 | Controller 不在启动类的包扫描范围内 | 确认 `PingController` 在 `com.liuxudong.areaecon.controller` 下 |

## 五、第四步：commit

### 先写 `.gitignore`（很重要，别漏）

在项目根目录建 `.gitignore`，内容：

```gitignore
# 编译产物
target/
*.class
*.jar
*.war
*.log

# IDE
.idea/
*.iml
.vscode/
*.swp

# 系统
.DS_Store
Thumbs.db
```

**为什么必须有它？** 因为 `target/` 里全是编译出来的 class 文件，几千个，提交上去又大又没意义，
面试官点开你的仓库只会觉得乱。`.idea/` 同理——那是 IDEA 的个人配置，别人打开会冲突。

### 然后执行三行命令

在项目根目录打开终端（IDEA 下方有 `Terminal` 标签页），依次执行：

```bash
git init
git add .
git commit -m "chore: 初始化 Spring Boot 项目骨架，跑通 /ping 接口"
```

### 验证

```bash
git log --oneline
```

应该看到你刚才那条 commit。

**再确认一下没把垃圾提交进去：**

```bash
git ls-files | head -30
```

如果列表里出现了 `target/` 开头的文件，说明 `.gitignore` 建晚了，执行下面这行把它从 Git 里移除：

```bash
git rm -r --cached target
git commit -m "chore: 移除 target 目录"
```
